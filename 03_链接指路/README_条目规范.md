# 05_链接指路 · 说明与条目规范

> 2026-09-13 周老师决策：文献库清洗后开源 GitHub。凡涉及版权、本地无全文或不便上传全文的资料，一律以「链接指路」形式存在于数据库（含 CNKI 论文）。
> 本目录为文献库的链接指路层：每件资料一条目，只存元数据与链接，不搬运有版权全文。

## 条目格式（所有板块统一）

```
## 条目名
- 类型：古籍原典 / 学术论文 / 专著 / 方志 / 集成卷 / 音视频 / 数据集 / 藏品 / 网页
- 链接：URL（详情页优先，不用搜索结果页）
- 平台 / 馆藏：
- 访问：✅公开全文 / 🔒机构或付费 / 🏛️仅到馆（附索书号） / ❌失效
- 本地状态：已入库（相对路径）/ 未获全文 / 仅链接
- 验证日期：2026-09-13
- 备注：
```

## 铁律（派工时已写入各 agent 任务书）

1. 每条链接必须实际访问验证，禁止编造 URL；查不到就老实写「未找到公开链接」。
2. 访问状态四档如实标注，🔒/🏛️ 不算失败——指路本身就是功能。
3. 各板块只写自己的输出文件，不动其他文件。
