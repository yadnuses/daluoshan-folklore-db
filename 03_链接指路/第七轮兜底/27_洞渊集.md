# 27 洞渊集——各版本与电子本搜集

> **文献简介**：《洞渊集》，宋李思聪撰，九卷。底本出自《正统道藏》太玄部。卷四"天下名山七十二福地"载"第二十六福地三皇井，在温州永嘉县"，为大罗山仙岩"第二十六福地"编号说的宋元之际关键文献证据。
>
> **与课题关系**：福地编号漂移研究的核心节点。《云笈七签》卷二十七（北宋）作"第二十九"，杜光庭《洞天福地岳渎名山记》（901）不编号，《洞渊集》（宋元之际）首次将三皇井编为"第二十六"，清代《图书集成》《浙江通志》沿用此说。
>
> **前轮已覆盖**：C4_古籍平台兜底_日本台湾.md 确认日本（早稻田、东洋文库、NDL）及台湾（台大佛学、中研院汉籍）五平台均未收录《洞渊集》独立条目。第五轮调研成果汇编已使用洞渊集卷四文本完成三书对勘。原16条（条目1-16）已覆盖主要中文电子本平台。本轮新增4条（条目17-20）：中华道藏电子版、三浦国雄学术论文全文链接、道藏第23册精确页码索引、daoist.org 学术引用 PDF。
>
> 验证日期：2026-09-14（第七轮兜底扩容）

## 与课题最相关的新发现 TOP3

1. **三浦国雄论文全文链接（条目18）**：澎湃新闻2023年1月刊载的三浦国雄《论洞天福地》中文全文。该文明确指出"洞天福地系统以《洞渊集》为下限被最终确定下来"，并对《天地宫府图》《洞天福地岳渎名山记》《洞渊集》三书的七十二福地进行比较，指出"福地名、位次、所在地与二者有着很大分歧"。这是理解洞渊集在洞天福地文献谱系中地位的**核心学术参考**，且该文对"第二十六福地三皇井"编号漂移问题有直接支撑意义。

2. **道藏第23册精确页码索引（条目19）**：safacura.org 提供的 PDF 索引确认洞渊集卷四位于《道藏》第23册第843-844页。此前各轮虽已使用洞渊集文本，但未定位到精确页码。此索引使论文注释可直接引用"《正统道藏》第23册，第843页"（1988年文物出版社等三家联合影印本），与 CNKI 学术论文中的引用格式一致。

3. **中华道藏电子版（条目17）**：dao.js.cn 将洞渊集收入《中华道藏·仙境名山志》（华夏出版社2004年版第48册），提供了区别于正统道藏本的另一电子文本来源。《中华道藏》是当代道教文献整理的重要成果，与《正统道藏》在编排上有所不同。

## 检索中遇到的困难

1. **ctext.org 反爬机制**：自动化 FetchURL 访问 ctext 时触发反爬验证页（"Attention researchers..."），无法通过工具直接抓取页面正文。但搜索引擎缓存的 snippet 已显示卷四关键文本"第二十六福地三皇井，在温州永嘉县"，且手动浏览器可正常访问。两个 ctext 条目（维基文字版 res=888230、OCR文字版 res=786553）均通过搜索引擎间接确认。

2. **日本/台湾平台确认缺失**：第六轮 C4 文件已确认五平台（早稻田、东洋文库、NDL、台大佛学、中研院汉籍）均未收录洞渊集。本轮未发现新的日本/台湾平台资源。

3. **"洞渊集"同名异书**：宋李思聪本（九卷，太玄部，洞天福地）与金长筌子本（五卷，太玄部，修炼论述）同名，ctext 和识典古籍均有收录。使用时需注意区分经号（DZ1063 vs DZ1064）。

4. **文本异文**：各转排版本存在少量异文——"东海"/"束海"、"沃洲"/"祆洲"、"鸡笼山"/"鹦笼山"等。以 Kanripo 涵芬楼影印原典图像（条目6）为最终校勘底本。

5. **dao.js.cn 需 JS 渲染**：中华道藏在线平台的页面需 JavaScript 渲染后才能显示正文，自动化工具只能通过搜索引擎摘要确认其存在，无法直接抓取全文。手动浏览器访问可正常阅读。

6. **ctcwri.idv.tw 已下线**：台湾道教经书研究会网站（ctcwri.idv.tw）曾收录洞渊集卷四全文，搜索引擎缓存显示"第二十六福地，三皇井，在溫州永嘉縣"，但该域名 DNS 已无法解析，确认已下线。未列入正式条目。
