## 检索中遇到的困难

1. **机构订阅墙**：中国数字方志库、爱如生中国方志库、万方地方志数据库、CADAL 四大综合方志库均为机构订阅制，无法在公网环境验证具体收录的温州方志条目。建议通过温州大学图书馆或温州市图书馆的馆内 IP 访问验证。
2. **温州大典 JS 渲染**：wenzhoudadian.ancientbooks.cn 为 JavaScript 动态渲染页面，外部工具无法直接抓取内容。平台需注册登录后方可检索，但根据温图年报和中国网报道，该平台确实已上线 424 种古籍且支持精确检索。
3. **温图古籍库访问限制**：温州市图书馆自建的"温图古籍库"（1880 种 5155 册）需读者证登录，部分资源可能限馆内 IP 访问，无法在公网验证具体收录内容。
4. **平台入口分散**：国家级古籍数据库体系庞大（中华古籍资源库、中华古籍书目数据库、全国古籍普查登记数据库、国家珍贵古籍名录数据库、全国联合发布古籍数字资源），各入口分散在 nlc.cn 不同子页面，且部分页面 URL 不稳定。本文已尽量记录直接入口。
5. **仙岩专题方志的版本辨识**：仙岩相关方志至少有五部——崇祯《仙岩志》（李灿箕，十卷）、康熙《仙岩寺志》（佛彦/佛皋，十卷）、民国《仙岩山志》（张扬，八卷），以及《仙岩志》民国抄本、《仙岩山志》部分卷次的 NLC 扫描件。各平台收录版本不同，检索时需注意区分。
6. **CADAL 主站域名不稳定**：cadal.zju.edu.cn 在公网环境无法解析（DNS 失败），需通过高校图书馆代理或 VPN 访问。识典古籍（shidianguji.com）作为 CADAL 数据源的前端，是更稳定的访问入口。
7. **国学大师网双域名**：guoxuedashi.net 和 guoxuedashi.com 两个域名均可用，但后者在部分时段返回 502 错误。建议优先使用 .net 域名。
