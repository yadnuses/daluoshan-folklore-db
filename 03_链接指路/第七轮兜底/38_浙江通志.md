## TOP3 与课题最相关的新发现

### 1. 识典古籍乾隆元年初刻本（NLG312001070176）

前轮仅使用光绪二十五年浙江书局重刊本（NLG312001070186），本轮首次引入乾隆元年初刻本标识。两个版本在识典古籍上均支持全文检索，可在线比对卷020仙岩山条、卷123端拱二年榜的版本异文。这对于辨析"姚揆端拱二年及第"一说的文本流传史有直接价值——如果初刻本已有此记载，则说明此说在雍正年间纂修时即已入志。

### 2. Wikimedia Commons NLC 分卷扫描（乾隆本卷123–126合卷 PDF）

NLC 国图将乾隆元年初刻本逐卷扫描上传 Wikimedia Commons，卷123–126 为合卷 PDF（选举门），含端拱二年陈尧叟榜原始影像。此扫描为未经 OCR 的原书影像，可与维基文库/识典古籍的 OCR 文本互校，排查 OCR 误识导致的姓名讹误（如"姚"字是否被误识为其他字）。

### 3. 识典古籍 SK1007 版本标识

SK1007 为识典古籍收录的雍正《浙江通志》又一版本入口，与 NLG 系列不同。全书支持全文检索，输入"仙岩""姚揆"可直达相关卷次。作为第三个可全文检索的在线版本，为交叉验证提供了冗余保障。

## 检索中遇到的困难

1. **Wikisource 全面超时**：本轮检索期间，wikisource.org 从当前网络环境完全不可达（curl 超时），无法重新抓取卷020、卷123 的全文。但前轮已验证过这些页面，且维基文库内容稳定，不影响链接的有效性判断。

2. **Wikimedia Commons PDF 下载超时**：upload.wikimedia.org 同样不可达，NLC 分卷扫描 PDF 未能实际下载验证页数和内容。但搜索索引（Google/WebSearch）确认这些 PDF 文件存在且被正确索引，链接结构完整。

3. **国学大师网 HTTP 502**：guoxuedashi.net 本轮返回 502 错误，无法访问其浙江通志卷262（大罗山条）页面。此为临时服务器问题，不影响链接长期有效性。

4. **中华文库 SSL 错误**：zhonghuashu.com 返回 curl SSL 错误（exit code 60），从当前环境无法验证。搜索索引确认其卷123页面存在。

5. **NLC 分卷扫描的卷次定位**：Wikimedia Commons 上的 NLC 扫描按物理分册编号而非卷次编号排列，需在 Commons 中逐个搜索"敕修浙江通志 卷XXX"才能定位特定卷次的 PDF。本次已定位到卷123–126、卷129、卷133、卷135 等选举门相关分卷，但寺观门（卷234）和经籍门（卷254）的 NLC 分卷 PDF 未能定位到确切链接。

6. **两个乾隆本标识的区分**：识典古籍上 NLG312001070176（乾隆本）和 NLG312001070186（光绪本）的命名关系需要确认——前者是否确实为乾隆元年初刻本，后者是否确实为光绪二十五年重刊本。两个标识均来自搜索结果的上下文推断，建议在识典古籍站内查看书籍详情页确认版本信息。
