## 与课题最相关的新发现 TOP3

### 1. 龙须潭（B-15）—— 龙母题叙事的百科级核心文本

百度百科「龙须潭」条目完整记载了黄帝乘龙升天时龙须堕落化为瀑布的传说，并引楞严遇安禅师诗「一逢旱魃解民愁」，将龙须潭的命名叙事与祈雨母题直接关联。此条目是课题龙母题叙事（龙须潭黄帝乘龙、祈雨仪式）在百科层面最集中的呈现。

### 2. 道家七十二福地（B-22）+ 洞天福地岳渎名山记（B-23）—— 福地编号漂移的文献学根源

B-22列出全部七十二福地，其中第29位「皇井（三皇井）——在温州横阳县」，第28位「陶山——在温州市瑞安市内」，与仙岩山条目引《云笈七签》的「第二十八福地」、杜光庭《洞天福地记》的「第二十六福地」形成编号差异。B-23则指出杜光庭所记「七十二福地」与《天地宫府图》「顺序番号大不相同」——这正是课题「福地编号漂移」议题的文献学根源。

### 3. 陈傅良（B-18）+ 梅雨亭（B-16）—— 仙岩书院与景观层累

陈傅良条目记载其「候职期间在仙岩创办书院」，梅雨亭条目引民国《仙岩山志》载「陈傅良的读书台位于梅雨亭上行百余步」，两相印证，确认了陈傅良在仙岩讲学的具体空间位置。这一发现将「永嘉学派—仙岩书院—止斋祠—梅雨亭—陈傅良读书台」的空间叙事链补全，是课题「景观锚定」议题的重要佐证。

## 检索中遇到的困难

1. **百度百科反爬**：百度百科部分条目（如 B-1 大罗山神话条目）FetchURL 返回 HTTP 403 Forbidden，无法直接验证全文。通过搜狗百科镜像（S-1）做替代验证。
2. **同名异义混淆**：「大罗山」在百度百科和360百科均存在同名条目，分别指温州和清远。360百科的「大罗山」实际描述的是广东清远，与课题无关，需特别注意辨析。百度百科有两个「梅雨潭」条目（ID:14274838 和 ID:5887680），内容详略有别，均收录。
3. **维基百科中文版覆盖不足**：维基百科中文版对大罗山的覆盖极为有限——「温州山峰」分类仅3个条目（大罗山国家登山健身步道、雁荡山、鹤顶山），无「大罗山」「仙岩山」「仙岩风景区」「圣寿禅寺」等核心条目。对比百度百科的丰富内容，维基百科中文版在大罗山主题上存在明显的条目缺失。
4. **温州仙岩寺无独立维基百科条目**：维基百科「仙岩寺」条目指向韩国全罗南道顺天市的仙岩寺（선암사），中国温州的仙岩寺（圣寿禅寺）在维基百科中无独立条目。百度百科「仙岩寺」条目亦指向韩国和广东潮州的同名寺院，温州仙岩寺以「圣寿禅寺」名义收录。
5. **梅雨潭无独立百科条目的旧判断已被推翻**：前轮报告称「梅雨潭无独立百科条目」，本轮实际验证发现百度百科有两个「梅雨潭」独立条目（ID:14274838 和 ID:5887680），内容丰富，前轮判断有误。
6. **限速问题**：WebSearch API 在短时间内多次调用后出现 429 限速错误，需间隔等待后重试。
