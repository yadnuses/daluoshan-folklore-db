# 22_潘耒：潘耒与仙岩寺志相关文献链接指路

> 检索目标：潘耒（1646—1708）生平传记、著作版本（重点《金石文字记补遗》《遂初堂集》系列）、潘耒校阅《康熙·仙岩寺志》的背景、与吴江师承及天目超智交往的研究材料。
>
> 检索日期：2026-09-14
>
> 前轮已覆盖要点：第四轮汇编详考寺志署名"吳江潘耒較閱"、卷九收潘耒《重建仙岩慧光塔序》全文、卷十收潘耒《游仙岩记》等三篇游记、外护名录"潘稼堂"条；第五轮汇编查明潘耒《金石文字记补遗》纠湖石塔三误；第三轮汇编提及梅雨潭得名由潘耒首释。以下精力放在前轮未充分展开的**潘耒著作版本系统、整理点校成果、学术传记资源**上。

此前四轮均未引及的**潘耒最详尽一手传记**。沈彤应潘耒之子所请撰写的行状，远详于《清史稿》本传，记录了潘耒师事顾炎武的具体过程、纂修明史"令撰食货志"的细节、甄别降调始末、"止止止"拒荐原话，以及"于声音反切，幼而神悟……乃著类音八卷"的音韵学成就。此篇在《碑传集》卷四十五（条目35）中亦有收录，两个版本可互校。识典古籍全文可读，PDF可下载。

### 2. 赖玉芹《试论潘耒对顾炎武学术的师承》（条目36）

潘耒-顾炎武师承关系的**核心学术论文**，被多部国家级社科项目引据。论潘耒在"史学、金石学、音韵学等方面均得到顾炎武的悉心传授"，直接关联本课题潘耒校阅《仙岩寺志》时运用的金石考证方法论。虽为🔒付费文献，但其论点已被多篇公开论文转引。

### 3. 王松木《务穷后世之变——论潘耒《类音》的音学思想与设计理念》（条目37）

台湾《汉学研究》2013 年发表的**潘耒音韵学专题论文**，38 页，PDF 全文可公开下载。系统论述潘耒《类音》的编撰目的、韵图设计理念、后人评价。潘耒"审五方之音而能得其会通"的音韵学素养，是理解其校阅寺志时审音辨字能力的重要背景。

## 检索中遇到的困难

1. **ctext.org 反爬机制严格**（同前轮）：中国哲学书电子化计划对自动化访问设置了强力拦截，无法直接抓取《遂初堂诗集》《类音》全文内容，仅能确认其存在并记录链接。
2. **《清代诗文集汇编》无公开数字版**（同前轮）：上海古籍出版社 2010 年影印本（第 170 册）无公开在线版本，需到馆查阅或购买。
3. **CNKI/万方限流**：本轮搜索过程中遭遇 HTTP 429 限流，部分学术论文（如赖玉芹文、屈大均潘耒与石濂交往关系考论）无法通过搜索引擎获取完整元数据，仅能记录已知信息。
4. **台湾学术数据库验证码**：台湾博硕士论文知识加值系统（NDLTD）对自动化访问设置了图形验证码拦截，虽确认链接有效但无法获取论文详情。
5. **华艺线上图书馆需机构订阅**：向惠芳《潘耒《类音》反切的变例及影响》等台湾期刊论文需机构权限方可阅读全文。
