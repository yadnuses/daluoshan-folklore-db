# 大罗山民间故事语料库·元数据说明

## 一、语料库简介

本语料库为「温州大罗山宗教民俗研究」课题组的核心成果之一，记录温州市大罗山（含仙岩、茶山、瑶溪、天柱寺等片区）民间故事、传说、灵验记、诗文证存等条目的元数据信息。

语料库经五轮系统调研建成（2026年9月13日），累计派出280余路子代理并行检索与细读。终版收录 **102 条**，构成如下：

| 文本形态 | 条数 | 说明 |
|:---|---:|:---|
| A 类（古籍原文） | 17 | 寺志、方志、类书、别集、碑记等直接照录 |
| B 类（旧籍引述/诗文证存） | 6 | 古人诗文可证该传说/景观当时已有文本锚点 |
| C 类（当代完整文本） | 59 | 政府网站、媒体、文史资料、网络文本中有完整故事文本 |
| D 类（仅篇目或概括线索） | 20 | 仅有书目/目录条目或征集设问，全文待读 |
| **合计** | **102** | A/B 类合计 23 条，C 类 59 条，D 类 20 条 |

## 二、四档分级定义

| 形态代码 | 定义 | 典型来源 |
|:---|:---|:---|
| **A** | 古籍原文——从寺志、方志、类书、别集、碑记等历史文献中直接照录的原始文本 | 《康熙·仙岩寺志》《钦定古今图书集成》《明一统志》《读史方舆纪要》、摩崖碑文 |
| **B** | 旧籍引述/诗文证存——古人诗文作品中涉及该传说或景观，可证其在当时已有文本锚点，但非独立故事全文 | 谢灵运诗、张璁诗、徐照诗、陈傅良文、王叔果游记 |
| **C** | 当代完整文本——当代来源中有可直接引用的完整故事文本 | 政府官网导游词、地方文史资料、媒体报道、网络自媒体、鼓词唱本 |
| **D** | 仅篇目或概括线索、无全文——仅有书目条目、目录篇名或征集设问中的概括陈述，全文尚待到馆/田野获取 | 《中国民间故事全书·瓯海卷》目录篇目、茶山街道故事征集设问 |

混合形态以"/"标注（如"A+C""B+C""C+A"），表示该条目同时具有两种形态的文本来源。

## 三、字段说明

| 字段名 | 说明 |
|:---|:---|
| **编号** | 1–102，与五轮调研汇编中的编号一致，不得重排。编号反映入库时间顺序（第三轮 1–40，第四轮 41–90，第五轮 91–102）。 |
| **故事名** | 条目名称，尽量保留汇编原题。括号内为补充说明或关键情节摘要。 |
| **关联景观** | 该故事关联的大罗山具体景观、地名或寺庙。多处景观以顿号分隔。 |
| **文本形态** | A/B/C/D 四档（见上），含并档者如"A+C""B+C"照汇编原样。 |
| **体裁** | 如传说、灵验记、俚语、本生叙事、曲艺文本、现代散文等。汇编未载明者留空。 |
| **来源或出处** | 古籍名/网站名/书名等文字描述，注明具体卷次或篇名。 |
| **来源URL** | 汇编中给出的 URL；多个 URL 以全角分号"；"分隔；无 URL 则留空。 |
| **备注** | 重要学术标注，包括但不限于：定性判断（如"传说附会，无宋人实证"）、证伪结论（如"晋代说证伪"）、互参说明（如"与第N条互参"）、待核标注（如"关系待核"）、并入说明等。 |

## 六、使用与引用建议

1. **编号引用**：引用语料库条目时请注明编号，如"大罗山民间故事语料库第 X 条"。
2. **URL 时效性**：来源 URL 为调研时点（2026年9月）的记录，部分网页可能失效；建议引用时同时注明"来源或出处"字段中的文字信息。
3. **文本形态意识**：A 类文本使用时须注意版本校勘（如寺志 OCR 讹字、潘耒纠误等，详见备注字段）；C 类文本反映当代文旅话语的增殖机制，不宜直接等同于口述传统；D 类条目全文待读，当前仅可作线索引用。
4. **证伪标注**：凡备注中标注"已证伪""附会""孤证待考"的条目，引用时须带此标注，不得作为信史直接使用。
5. **互参条目**：第 67 条与第 98 条（卧龙潭系列）、第 74 条与第 102 条（遂川/逆川和尚）存在关联，引用时建议互参。
6. **D 类升级路径**：第 76–90 条（共 15 条）出自 2024 年《中国民间故事全书·瓯海卷》目录，文本待到馆精读后升级为 C 类；升级后的全文将通过来源 URL 指路，本表同步更新。
